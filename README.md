# Averra Solentra website
npm install
npm run dev     # local preview
npm run build   # static output in dist/ (upload to any static host)

Notes:
- Replace PHONE in src/App.jsx with the full number.
- Images are Unsplash links in the IMG object (App.jsx). Swap for your own photos.
- "SF Pro Text" is Apple's licensed font. It renders on Apple devices; others fall back to Inter.
